# 🍷🥃 Web Scraping APIs – TotalWine & SpecsOnline

##  Features

-  Automated scraping (no manual work manual-work for captcha)
-  Supports **multiple websites**
  - TotalWine
  - SpecsOnline
-  Separate APIs for:
  - Wine
  - Spirits
-  Handles pagination (100+ pages)
-  Saves data as:
  - `.json`
  - `.xlsx`
-  Clean MVC-style folder structure
-  Tested using Postman

---

##  Tech Stack

- Node.js
- Express.js
- Puppeteer
- xlsx
- Postman (for API testing)
